# World Info Visualizer

See which lorebook entries were used in Lumiverse's latest response, at a glance.

## Installation

1. Open Lumiverse's **Extensions** panel and install from this repository.
2. Grant the requested permissions and enable the extension.
3. Open a chat and generate a response.
