# World Info Visualizer

See which lorebook entries were used in Lumiverse's latest response, at a glance.

A floating globe shows the number of active entries. Click or tap it to see their exact names, grouped by lorebook.

## Features

- Entries grouped by lorebook for easy browsing.
- Blue pins for constant entries, green keys for keyword entries, and violet links for vector entries.
- A draggable globe with an adjustable size in the extension's settings.
- Colors that follow your Lumiverse theme.

Click the globe again, click outside the list, or press Escape to close it. When there are no active entries, the globe has no number and the list shows `?`.

Results appear after generating a response. Switching chats or reloading the extension clears the list until the next generation.

## Installation

1. Open Lumiverse's **Spindle / Extensions** panel and install from [this repository](https://github.com/Tantoofaaz777/Lumiverse-WorldInfo-Visualizer).
2. Grant the requested permissions and enable the extension.
3. Open a chat and generate a response.

Use the extension's **Configure** button to change **Floating icon size**.
